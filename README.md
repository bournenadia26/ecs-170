# ecs-170

Quarter-long AI course project for ECS 170: Artificial Intelligence (UC Davis, Spring 2026).
Five-stage project building progressively more complex neural network models in PyTorch,
from basic classification to graph neural networks.

## Stages

| Stage | Task | Model |
|---|---|---|
| 2 | Tabular data classification | MLP |
| 3 | Object recognition from images | CNN |
| 4 | Text classification and generation | RNN / LSTM / GRU |
| 5 | Graph embedding and node classification | GCN |

## Stack

Python, PyTorch, Scikit-Learn
